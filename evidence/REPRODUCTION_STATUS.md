# What a stranger can reproduce today

## Available from this public Pages repository

- Human-readable MathCase result summaries and exact source locations.
- M20 composition source files, shard receipts, two fresh source-replay hash/timing tables, grouped axiom output, and the source-binding addendum.
- A public slice of 4,262 theorem statements with hash-checked local browser search.
- The M31 affine-bound source, input files, and successful independent arithmetic-verifier receipt.
- Three affine Collatz family sources with saved local Lean receipts.
- Erdős–Straus aggregate audit/summary and per-range maxima; public per-witness payloads are only independently bundled through `d ≤ 1,000,000` on the MathCase showcase branch.
- The Ramsey finite-graph construction, exact checker, graph6 output, and receipt.

## Still open

The pinned Docker image used for the M20 and affine Lean runs is not anonymously pullable, and its complete rebuild context is not staged here. The M20 phase outputs are large; OLEAN binaries were intentionally omitted, while file hashes and text evidence are available. Therefore a stranger cannot yet repeat the flagship Lean replay from a fresh public checkout using only this site.

The top-level M15–M20 export manifest is omitted because it contains a pointer to a non-public source branch. The shard statements, source hashes, axiom records, and receipt rows included in the public graph slice remain individually bound; the narrower M20 composition subpackage has its own manifest.

Independent human review remains open. The M20 shard records do not have individual M0 review; M4 was not promoted. The finite Ramsey target has no owner M0 answer yet and no Lean proof. The model-based transfer comparison and learner evaluation are staged, not run; no model calls are running and spend is $0.

The MathCase release candidate remains on Ryan's GitHub-import/review path. This site publication does not push or merge the MathCase repository.
