# Public site release scope

Recorded November 18, 2026, by the site contributor from Ryan's explicit instruction to publish the public-safe MathCase results on DarthCeltic.github.io.

This publication authorizes public display on this site of the MathCase-authored theorem sources, finite computation reports, and saved receipts included in this release. It is not a signature, M0 review, M4 promotion, independent review, or a new permission for model training, provider input, external proof reuse, or derivative licensing.

Historical receipt fields are preserved as recorded for their original runs. Where an older receipt says public use was not previously granted, this site's owner-directed release scope records the later publication decision without altering the historical receipt bytes.

The release does not push or merge the MathCase repository's staged release candidate, and it excludes restricted dossier/evaluation material, workstation-only raw setup logs, and private coordination notes. The MathCase repository itself remains on Ryan's GitHub import/review path.
