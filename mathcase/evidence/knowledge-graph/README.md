# Browse the public theorem index

This site includes a public slice of **4,262** exact Collatz shard statements. The browser tool on the All Work page checks the pinned manifest, index, and record-file SHA-256 values before it searches. Search is literal text/name matching; it is not semantic retrieval and does not infer that one lemma proves another.

Each result exposes the formal statement, source path and digest, listed dependencies, axiom report, and per-shard receipt binding. Every record says that its individual statement has not received M0 review and that no M4 promotion is recorded. The slice excludes 29 owner-only/out-of-package records and three historical aggregate entries; it contains no owner graph, personal paths, locked benchmark text, or restricted dossier material.

The MathCase source tree and receipts are present under `../collatz/m15-m20-pinned-replay/`. The slice manifest and hash files are in `public-slice-v1/`. Dependency listings do not claim a normalized full imported-constant closure. No clean-room Lean rebuild is established by this index.
