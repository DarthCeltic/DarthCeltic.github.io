# Candidate identity that did not add coverage

One algebraic lead considered the progression `n = 312t + 169 = 13(24t + 13)` for each nonnegative integer `t`. Let `m = 24t+13`, `x=(n+7)/4=78t+44`, `y=2mx`, and `z=26mx`. Then

```text
1/x + 1/y + 1/z = 4/n.
```

The identity is valid for the stated nonnegative parameters, but it does not enlarge the known covered set: the known identity `4/13 = 1/4 + 1/18 + 1/468`, scaled by `m`, already covers every `n=13m`. This is a checked construction lead rejected as a new coverage result, not a new theorem claim.
