How do two windows shape the first drop?

Use the shortcut rule: halve an even input; for an odd input, apply (3n + 1)/2. Count odd inputs in the first 12 shortcut steps, then in the next 12. The atlas compares every pair of allowed counts and records when a start first falls below itself.

This explores bounded first-drop conditions. It does not test whether every Collatz sequence eventually reaches 1.

      What the atlas counts

      The atlas divides the first 24 shortcut inputs into 16,777,216 parity classes modulo 224. It checks the least start n ≥ 3 in each class. A separate affine audit then classifies all larger members of that class: every start drops by step 24, some do, or none do. Each cap pair combines the exact classes it allows. A full-coverage filter guarantees a first drop for every qualifying start. A partial filter shows its non-dropping example instead of presenting it as a bound.

      The shortcut step combines two ordinary moves when its input is odd and one ordinary move when it is even. If the first drop takes t shortcut steps and those inputs include h odd terms, it takes t + h ordinary steps.
