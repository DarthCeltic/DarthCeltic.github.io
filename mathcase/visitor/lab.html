Check your own weak-Schur partition

Choose a finite bound n, then enter one color for each integer 1 through n. The checker tests the exact predicate “no monochromatic a < b with a + b ≤ n,” excluding equal addends. It runs locally; a pass is only a pass for the data and bound you supplied.

Enter exactly n color labels, then check.

What this does and does not establish

This is an exhaustive browser enumeration of the finite triples for your selected bound. It does not search for a better coloring, prove a general theorem, run Lean, or identify who supplied the data. Exported receipts are unsigned JSON artifacts: import verifies their content hash and recomputes the predicate before displaying the result.
