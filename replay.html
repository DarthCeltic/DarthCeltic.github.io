Checking a Collatz proof

Does the same proof check twice?

Start at 239 and take 32 ordinary Collatz steps. You finish at 122. MathCase has a proof that gives the exact endpoint for every starting number in 2,652 listed families. On November 18, two runs rebuilt that proof from the same source files. Lean accepted every file both times.

See the math behind 239Compare one proof file

What agreed in the two runs?

Each run checked 363 files, from small pieces of the proof to the final theorem. For each file, both runs read the same text, produced identical compiled proof files and recorded the same compiler messages.

The first run reached its two-hour timer after the mathematical checks finished. The second exited normally. Both ran in the same software environment. That agreement tells us what happened there.
