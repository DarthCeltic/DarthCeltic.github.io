About review files and self-hosting

A review includes a fingerprint of the learner’s submitted file. It identifies which file received feedback. It does not verify anyone’s identity.

The optional Go classroom service stores accounts, assignments, and responses locally. It does not check proofs or create receipts. Keep it on your computer and read the setup and security limits before use.
