Help with writing a proof

Write what you think the example shows. Lean is a proof checker. It checks whether the code proves the statement written in Lean. You decide whether that statement captures your idea.

Write your claim and its assumptions. Under “Statement in Lean,” enter the same claim as a Lean proposition and give the name of the theorem in your proof code.

The local checker appends a theorem of the exact target type, applies the named declaration, and prints its axiom dependencies. Review the English statement against the target yourself.

Online checks and saved receipts

The online editor shows compiler output. It chooses its own Lean and Mathlib versions, which may differ from the MathCase local checker (Lean 4.33.1). To save a receipt, use the local check below.

Prefer a separate window?

The editor opens here. Press its Run control to check the code. Copy any edits back into this workbench to save them.

If it says “No connection to Lean” or stays on “Updating…”, the online checker has not checked your proof. Choose Reconnect from draft to reload the code currently in this workbench. Copy any changes from the editor back here first. If it still cannot connect, use the pinned local check below.

Check locally and save a receipt

Choose Save the whole claim to download a packet with the plain claim, exact proposition, theorem name, and Lean source. Place it in the MathCase checkout and run the command below. The starter uses Lean Core. For sources importing Mathlib, use an already prepared Lean 4.33.1 project and add --lake-project PATH; this command does not fetch packages.

A MathCase Codespace can install the pinned Lean Core toolchain; Mathlib is not included by default.

Load the receipt to see whether its claim, proposition, theorem name, and proof code match this draft. The fingerprints identify the saved content. MathCase does not sign visitor receipts.
