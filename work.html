Number sequences · Collatz

When must a number fall below its start?

Start with a whole number. If it’s even, halve it. If it’s odd, triple it and add 1. Each of those is one ordinary step.

A shortcut combines the odd step and the next halving. For a start of 3 or more, count how many of the first 23 shortcuts begin on an odd number. If the count is 14 or fewer, the sequence falls below its start within 37 ordinary steps. Lean, a mathematical proof checker, verified that guarantee. Whether every positive start eventually reaches 1 remains open.

When does 5 first drop below 5?

Count by

5 → 16 → 8 → 4

Three ordinary steps. The first value below 5 is 4.

In shortcuts, 5 → 8 → 4 takes two moves. In odd-to-odd counting, 5 → 1 takes one move because all the halvings are grouped together.

Plain statement: for every start n ≥ 3, if at most 14 of the first 23 accelerated inputs are odd, the ordinary Collatz iterate at step 23+h is smaller than n, where h is the exact odd-input count.

Other Collatz results and the starting-number calculator
Why do 2,652 number patterns drop after 32 ordinary steps?

Start with 239. After 32 ordinary steps it reaches 122. The proof covers 239 plus any multiple of 1,048,576 and 2,651 other patterns of starting numbers.

Plain statement: for each exact pair (r,q) listed in the checked Lean source and every natural k, start at 1,048,576k+r. After exactly 32 ordinary Collatz steps, the value is 531,441k+q, and that endpoint is smaller than the start.

C³²(2²⁰k + r) = 3¹²k + q < 2²⁰k + r, for each of the 2,652 source-listed (r,q) pairs

The Lean theorem states the equality and the strict inequality together. The map C sends even n to n/2 and odd n to 3n+1. A separate exact coefficient audit finds start − endpoint = 517,135k + (r−q); every listed intercept gap is positive, with minimum 117.

Two agreeing replays363 Lean files each · 23 axiom groups · 4,262 queries · zero sorryAx reports

The final theorem reports only propext and Quot.sound. Across both phases, all source, expected/produced OLEAN, stdout, stderr, and Lean exit-code hashes agree; timing and run-metadata hashes vary. This is a bounded first-descent result for the listed progressions, not a proof that every Collatz trajectory reaches 1.

Replay boundary: the runs used two fresh isolated workspaces, not two separate Git clones. The pinned Lean image supplied 346 Mathlib dependency OLEANs. The Phase 1 runner completed all Lean and axiom checks, but its Docker wrapper returned 124 when an added two-hour watchdog expired; Docker did not report OOM. Phase 2 returned 0.

Fractions · Erdős–Straus

Can three fractions with a 1 on top add up to 4/n?

A fraction like 1/7 is called a unit fraction. Choose n = 21 and three of them add up to 4/21. A formula extends examples like this one to every number of the form 28k + 21 for k = 0, 1, 2, …

A separate search found exact answers for all 831,860 numbers in its filtered set. Whether every integer n ≥ 2 admits such a sum remains open.

Direct algebraic identity · statement review open · no Lean attempt

A three-fraction formula for every n = 433 + 840t.

Plain statement: for every integer t ≥ 0, set n = 433 + 840t. The formulas below give positive, strictly increasing denominators whose unit fractions add exactly to 4/n.

Formula: A = n(n+7)/4, x = (n+7)/4, y = (A+5)/7, and z = A(A+5)/35, so 4/n = 1/x + 1/y + 1/z.

Here n ≡ 1 (mod 4), n ≡ 3 (mod 5), and n ≡ 6 (mod 7). These make x and A integers; they also give A ≡ 0 (mod 5) and A ≡ 2 (mod 7), so y and z are integers. Since y−x = (x(n−7)+5)/7 > 0 and z/y = A/5 > 1, the denominators are ordered.

The identity follows by subtraction: 4/n − 1/x = 7/A, then 7/A − 1/y = 1/z. This covers one progression, not every integer. It does not settle Erdős–Straus. A 2026 paper studies the same first-denominator shift c=7 in a related prime case; no novelty claim or broad literature search is made.

Graph coloring · Ramsey

How many dots can avoid a one-color group of five?

Connect every pair of dots. Color each line red or blue. Six dots always contain a one-color triangle. Now look for five dots whose ten connecting lines are all the same color.

A known arrangement of 42 dots avoids every such group. Lean checked this arrangement. That shows that a guarantee for five must start at 43 dots or more. This example alone cannot tell us the exact threshold.

Prime numbers · Proof checking

What went wrong in the AI’s first proof?

A prime that divides a square also divides the number you squared. For instance, 3 divides 36 and also divides 6. The proof had to work for every prime and every square.

The AI supplied “divides the square” when Lean first needed “is prime.” It supplied both facts in the correct order on its second attempt. Lean accepted the repaired proof of this known theorem.

The first saved candidate was rejected by Lean because it used the divisibility assumption where the theorem required primality. The repaired candidate used both assumptions and its saved Lean check passed.
