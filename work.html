Fresh source-to-kernel replay · bounded theorem

A precise Collatz descent statement for 2,652 listed progressions.

Plain statement: for each exact pair (r,q) listed in the checked Lean source and every natural k, start at 1,048,576k+r. After exactly 32 ordinary Collatz steps, the value is 531,441k+q, and that endpoint is smaller than the start.

C³²(2²⁰k + r) = 3¹²k + q < 2²⁰k + r, for each of the 2,652 source-listed (r,q) pairs

The Lean theorem states the equality and the strict inequality together. The map C sends even n to n/2 and odd n to 3n+1. A separate exact coefficient audit finds start − endpoint = 517,135k + (r−q); every listed intercept gap is positive, with minimum 117.

Two agreeing replays363 Lean files each · 23 axiom groups · 4,262 queries · zero sorryAx reports

The final theorem reports only propext and Quot.sound. Across both phases, all source, expected/produced OLEAN, stdout, stderr, and Lean exit-code hashes agree; timing and run-metadata hashes vary. This is a bounded first-descent result for the listed progressions, not a proof that every Collatz trajectory reaches 1.

Replay boundary: the runs used two fresh isolated workspaces, not two separate Git clones. The pinned Lean image supplied 346 Mathlib dependency OLEANs. The Phase 1 runner completed all Lean and axiom checks, but its Docker wrapper returned 124 when an added two-hour watchdog expired; Docker did not report OOM. Phase 2 returned 0.

What “M20” means and how to read this percentage

The number is the exponent: M20 means 2²⁰ = 1,048,576 possible remainders. This is a finite fraction of one residue space, not a percentage of the Collatz conjecture solved and not a natural-density statement. The 2,652-family composition theorem above is one exact theorem within the larger recorded tier; the count comes from a separate family-basis audit.

The underlying audit checked 4,262 saved family rows, 229 shard modules, 496 input bindings, and the 7,825-class M13 seed. It did not compile Lean or rescan trajectories. An older README rounds this number incorrectly as 97.395%; the correction is recorded beside the preserved historical artifact.

Independent exact arithmetic check · not Lean

For 23.6 million saved classes, the third accelerated iterate stays above a precise line.

Plain statement: for every positive member n of each saved odd class modulo 2³¹, after three accelerated odd-to-odd steps the value satisfies 16*T³(n) − 27*n ≥ 19.

T³(n) ≥ (27n + 19) / 16 · sharp on 4,146,987 saved classes

This compares the third iterate with the original start; it does not say the sequence increases at every individual step. The independent verifier rehashed 30 source/input bindings, checked the population count and sharp stratum, and did not rescan trajectories.

This is an exact arithmetic corollary of recorded affine formulas, not a Lean theorem. It does not establish a fourth-step decrease, cover all odd numbers, or prove convergence.

Exact finite construction check · known result

A 42-vertex graph reproduces a known lower bound for R(5,5).

Plain statement: a checked two-coloring on 42 vertices has no monochromatic clique of size five. This gives the known bound R(5,5) ≥ 43.

The local checker examined all 850,668 five-vertex subsets of the reconstructed Exoo(42) graph. It is a reproduction of a known finite construction, not a new theorem. No Lean proof is included. The owner M0 statement review is unassessed; the exact question is staged privately.

A separate supplied certificate failed an order check: its metadata said 42 vertices but its graph6 bytes decoded to 41. That failed input is preserved and is not used for the passing construction.
