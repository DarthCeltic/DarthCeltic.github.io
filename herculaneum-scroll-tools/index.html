Herculaneum Scroll Tools

Open-source utilities for examining Herculaneum scans. Compare two X-ray energies, register old and new scans, check predicted surfaces against CT data, and annotate winding constraints on rendered surfaces.

Open the GitHub repository ↗

Explore the project

The repository includes the commands and examples. The tools use public Vesuvius Challenge data, and the scan utilities can stream the data they need.
