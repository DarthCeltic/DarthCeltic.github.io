Finite trajectory check

Check a Collatz trajectory

For one supplied starting number, MathCase follows standard Collatz steps and reports whether a value below that start appears within your step limit.

T(n) = n/2 for even n; T(n) = 3n+1 for odd n.

Ready. Nothing runs until you submit the form.

What a pass means: this exact starting number reaches a smaller value within the checked steps. A residue-mode run checks one chosen k only. It does not prove the result for every k, prove convergence, or replace Lean.

Bounded exact search

Search an Erdős-Straus member

For n = 12d+1, MathCase searches your finite denominator bounds for positive, strictly increasing x, y, z that satisfy the exact equation.

4/n = 1/x + 1/y + 1/z

Ready. The search is bounded and stays in this browser.

What a witness means: the displayed tuple satisfies the exact integer identity for this one n. A bounded miss means only that no witness appeared within the searched bounds; it is not a counterexample to the conjecture.

About the receipts

Each receipt records its inputs, finite bound, exact result, and a SHA-256 digest over the canonical result fields. Downloading saves a JSON file to your device. Saving stores the receipt in this browser's local storage only; it is not uploaded or shared.

For an arbitrary Lean statement and proof attempt, MathCase still needs a self-hosted Lean WASM runtime. The host has Lean 4.33.1 but not its browser build tools or WASM files, so this page does not pretend a JavaScript calculation is a kernel-checked proof.
